# Java 12 through 20

## switch-expression

**Minimum: Java 14.** Use a switch expression when every branch computes one
value and fall-through is not part of the behavior.

```java
// Before.
int priority;
switch (kind) {
    case FAST: priority = 1; break;
    case NORMAL: priority = 2; break;
    default: priority = 3;
}

// After.
int priority = switch (kind) {
    case FAST -> 1;
    case NORMAL -> 2;
    default -> 3;
};
```

Use `yield` in a block that computes the result. Preserve branch side effects,
null behavior, and intended fall-through. Expressions must be exhaustive.
An ordinary switch expression does not grant pattern matching: type-pattern
cases require Java 21 in this stable catalog.

Source: [JEP 361](https://openjdk.org/jeps/361).

## text-blocks

**Minimum: Java 15.** Use a text block for a multiline literal when it makes
the content clearer and preserves the exact required string.

```java
// Before.
String query = "SELECT id\n"
    + "FROM account\n"
    + "WHERE active = ?\n";

// After.
String query = """
    SELECT id
    FROM account
    WHERE active = ?
    """;
```

Check incidental indentation, trailing spaces, newline normalization, and the
final newline. Text blocks are not raw strings or interpolation; escapes still
apply. Keep SQL parameter binding and existing output escaping. For protocols
or snapshots, compare the resulting characters or bytes.

Source: [JEP 378](https://openjdk.org/jeps/378).

## instanceof-pattern

**Minimum: Java 16.** Combine an `instanceof` check with binding when the old
code casts the same value after the check.

```java
// Before.
if (value instanceof String) {
    String text = (String) value;
    consume(text);
}

// After.
if (value instanceof String text) {
    consume(text);
}
```

The binding is available only where a successful match is established, such
as the right-hand side of `&&`, not generally `||`. Null still fails the test.
Preserve the number and order of evaluations if the old expression calls a
method or reads mutable state.

Source: [JEP 394](https://openjdk.org/jeps/394).

## records

**Minimum: Java 16.** Prefer a record for a new transparent value carrier whose
component-based equality and accessors match its intended contract.

```java
// New internal value: construction establishes its invariant.
record PageRequest(int page, int size) {
    PageRequest {
        if (page < 0 || size < 1) {
            throw new IllegalArgumentException("invalid page request");
        }
    }
}
```

Converting an existing class is a contract change to assess, not a boilerplate
deletion. Records are final, have component accessors such as `page()` rather
than `getPage()`, and derive equality/hash code from their components. Check
constructors, inheritance/proxies, bean conventions, annotations, serialization,
and consumers before conversion; verify the actual framework versions.

Component fields are final, but referenced collections and arrays remain
mutable. Establish appropriate defensive-copy rules for input and accessors
when deep immutability is required. Array components also retain array identity
equality by default. Keep ordinary classes for mutable entities or contracts
that need those class semantics.

Source: [JEP 395](https://openjdk.org/jeps/395).

## stream-to-list

**Minimum: Java 16.** Use `Stream.toList()` when downstream code expects an
unmodifiable list in stream encounter order.

```java
// Before: this result is intended to be unmodifiable and may contain nulls.
List<String> names = Collections.unmodifiableList(users.stream()
    .map(User::getName).collect(Collectors.toCollection(ArrayList::new)));

// After.
List<String> names = users.stream().map(User::getName).toList();
```

Trace consumers before replacing `collect(Collectors.toList())`; mutating the
new list throws. The JDK's stream implementations accept null elements in
`toList()`, while `Collectors.toUnmodifiableList()` and `List.copyOf()` reject
them; the javadoc promises this only through the interface's `@implSpec`
default, so confirm the null policy at the source rather than relying on it. Generic
inference can also differ: assigning a stream of `String` to `List<CharSequence>`
may require an explicit stream type witness. Choose
[an explicit mutable collector](JAVA8.md#mutable-stream-result) when mutation
is required. Do not promise a concrete implementation or serializability.

Source: [Java 16 Stream.toList](https://docs.oracle.com/en/java/javase/16/docs/api/java.base/java/util/stream/Stream.html).

## sealed-types

**Minimum: Java 17.** Use sealed classes/interfaces for an intentionally closed
domain hierarchy controlled by the same owner.

```java
// New closed result model.
sealed interface Lookup permits Found, Missing {}
record Found(String value) implements Lookup {}
record Missing() implements Lookup {}
```

Each permitted direct subtype must be final, sealed, or non-sealed (records
are final). Subtypes must be in the same named module, or the same package in
the unnamed module. Sealing an existing public extension point can break
consumers and runtime proxies. Preserve open extension contracts. Java 17
supports this hierarchy, but exhaustive type-pattern switch becomes stable
only in Java 21.

Source: [JEP 409](https://openjdk.org/jeps/409).

## executor-close

**Minimum: Java 19.** `ExecutorService` supports try-with-resources when the
scope owns the executor and is intended to wait for its tasks to finish.

```java
// New bounded scope: process all work before returning.
try (ExecutorService executor = Executors.newFixedThreadPool(4)) {
    Future<Result> result = executor.submit(this::compute);
    consume(result.get());
}
```

`close()` initiates shutdown and waits for termination. Replacing a plain
`shutdown()` in `finally` can turn non-blocking cleanup into an unbounded wait.
Preserve deadlines/cancellation and avoid closing a shared or borrowed
executor. A locally returned `Future` must not accidentally become synchronous
because scope exit waits for it. Java 8–18 needs explicit executor shutdown
according to the intended lifecycle.

Source: [Java 19 ExecutorService.close](https://docs.oracle.com/en/java/javase/19/docs/api/java.base/java/util/concurrent/ExecutorService.html).
